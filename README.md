# AI 网页公式复制乱码清洗与纯文本 Unicode 转换工具

专治从 **ChatGPT、Claude、Gemini、DeepSeek** 等网页局部框选包含数学公式的文字并复制（`Ctrl+C`）时出现的**双倍重影、句子碎成十几行、hat/转置/下标脱落、混入 `U+200B` 零宽空格**等排版损坏，同时支持将原始 LaTeX（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`）一键转为高可读性的纯文本 Unicode。

---

## 一、快速使用（零安装、离线即用）

1. 直接用任意浏览器双击打开单文件工具 **[`index.html`](./index.html)**（该文件已完整内联核心引擎，可单独拷贝到桌面、收藏夹或任意电脑离线使用）。
2. **极速三步闭环**：
   - 在 AI 网页框选复制文字（`Ctrl + C`）；
   - 切到工具页面直接按 **`Ctrl + V`**（无需先点进输入框，默认已开启「粘贴后自动复制」）；
   - 直接切回 **Word / PPT / 微信 / 飞书 / 纯文本编辑器** 按 **`Ctrl + V`** 粘贴干净结果。
3. 也可直接点击顶部 **「📋 一键粘贴并清洗复制」** 按钮完成读取剪贴板 → 清洗 → 写回剪贴板全流程。

---

## 二、核心特性与偏好调节

- **双通道自适应解析**：
  - **网页富文本无损通道**：当直接从浏览器复制粘贴时，若剪贴板包含 `.katex` / `mjx-container` / `<math>` DOM，优先提取底层 `<annotation>` 或 MathML 语义树，同时严格保留原网页段落与列表。
  - **纯文本双层重影重建引擎**：当输入为纯文本（如二次粘贴、记事本中转文本）时，基于“MathML 碎片流 ↔ HTML `.vlist` 视觉流”多重集守恒与垂直空行签名，精确还原顶标（`ẑ`、`x̄`、`p̃`、`v⃗`、`ẋ`）、上下标（`z_ctx`、`μ_B`、`x_i²`）、分式、根式与巨型算符上下限，绝不误合并真实段落换行。
- **原始 LaTeX 兼容**：自动识别并转换 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 公式（智能避开 `$100` 等普通金额文本）。
- **可调排版偏好（自动记忆）**：
  - **下标风格**：默认「智能一致」（字母与多字符下标用 `z_ctx`、`μ_B`，独立单数字下标用 `x₁`，同公式混排时自动统一为 `_1` 防割裂）；可切换为「统一使用下划线」。
  - **算符间距**：支持标准单空格（`Δz = z_ctx − z_base`）与紧凑模式（`Δz=z_ctx−z_base`）实时切换。

## 三、文件结构与开发测试

- `index.html`：自包含单文件离线工具（双击即用，零外部依赖）。
- `cleaner.js`：核心清洗与转换引擎（UMD 模块，同时兼容浏览器与 Node.js）。
- `cleaner.test.js`：自动化验收测试套件（覆盖真实基准样例、高压脏字符及 20 项边界案例）。
- `build.js`：将 `cleaner.js` 同步内联打包至 `index.html` 的构建脚本。

### 运行自动化测试
```powershell
node cleaner.test.js
```

### 修改引擎后重新打包单文件 HTML
```powershell
node build.js
```
